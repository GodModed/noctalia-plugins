# GodMode's Noctalia Plugins

## Install
1. Install [Noctalia](https://docs.noctalia.dev/getting-started/installation/)
2. Add this repository to Noctalia as a plugin source
3. Install my plugins!

## Plugins

* Animated Wallpapers - Adds support for animated wallpapers from within Noctalia
    - Dependencies:
        - ffmpeg
        - mpvpaper
        - socat
